# VoiceText

轻量 macOS **菜单栏** 语音输入工具：按住 Option 说话，松开后由 **豆包语音识别** 出字，并自动插入当前输入框。两种识别方式：

- **一句话识别**（默认）：松手后返回整句，准确率更高
- **实时识别**：边说边出字，按分句立即插入

## 安装

```bash
curl -fsSL https://raw.githubusercontent.com/Aarontaken/voice-text/main/install.sh | bash
```

脚本会拉取最新 Release 装到 `/Applications`，过程中需要输入管理员密码。也可以从 [Releases](https://github.com/Aarontaken/voice-text/releases) 下载 zip 自行解压拖入 `/Applications`。

> 首次打开若提示未验证开发者，右键 App 选择 **打开** 即可。

需要 macOS 13 或更高版本。

## 首次配置

1. 在[火山引擎控制台](https://console.volcengine.com/speech/new/setting/apikeys)开通「豆包流式语音识别」，并创建 **API Key**。
2. 菜单栏 VoiceText → **设置**，粘贴 API Key。
3. **模型版本** 选与控制台已开通资源一致的一项（默认「2.0 小时版」）。
4. 保存。

> 豆包按音频时长计费，使用前请确认账号已开通对应资源。

## 使用

| 操作 | 效果 |
|------|------|
| 按住 **⌥ Option** 0.25 秒 | 开始录音 |
| 松开 Option | 结束录音，出字并写入当前输入框 |
| 双击 **⌃ Control** | 开始连续录音（免提）；再双击结束 |

连续录音期间按 Option 不会触发新的录音。识别过程中 HUD 会显示状态与预览文本。

插入文字走的是「写剪贴板 + 合成 ⌘V」，不按应用做区分：浏览器、编辑器、终端都是同一条路径。粘贴前会备份剪贴板，粘贴完成后恢复原内容。

处于**安全键盘输入**（密码框等）或未授予辅助功能权限时，合成按键会被系统丢弃；这时识别结果会留在剪贴板上，手动 ⌘V 就能取回，不会丢字。

## 设置项

| 项 | 说明 |
|----|------|
| 识别方式 | 一句话识别 / 实时识别 |
| 完成停顿 | VAD 静音判停阈值，默认 800ms，范围 300–5000ms；调小出字更快但更易切断，调大更稳但等得更久 |
| 模型版本 | 2.0 小时版（推荐）/ 2.0 并发版 / 1.0 小时版 / 1.0 并发版，需与控制台开通的资源一致 |
| 识别语种 | 自动（中英混合，默认）/ 中文普通话 / English |
| 数字/日期规范化 | 把口语里的数字、日期转成书面格式 |
| 自动标点 | 自动补逗号、句号等标点 |
| 语义顺滑 | 去掉语气词、重复词，让句子更连贯 |

## 权限

- **麦克风** — 录音必需，首次录音时系统会询问
- **辅助功能** — 投递合成 ⌘V 必需。缺少授权时插入会失败并把结果留在剪贴板，此时会弹窗提示，也可从菜单栏直接授权

## 更新 / 卸载

- 更新：重新执行安装脚本，或下载新 Release 覆盖 `/Applications/VoiceText.app`
- 卸载：退出 VoiceText，删除 `/Applications/VoiceText.app`

## 常见问题

**外接显示器、合盖后按住 Option 没反应？** 合盖（clamshell）时 macOS 会在硬件层断开内建麦克风，任何应用都无法重新打开，采集链路不报错、只送出一路静音。接一支外置麦克风（USB 麦克风、蓝牙耳机或 iPhone 连续互通麦克风）并选中它即可，或者打开机盖。录音前检测到这种情况会直接弹窗说明，不再静默失败。

**按住 Option 完全没有动静？** 看菜单栏状态：显示 `!` 说明被拦下（见上一条的弹窗提示）；毫无反应则检查 系统设置 → 隐私与安全性 → **辅助功能** 是否勾选 VoiceText，部分系统还需授权 **输入监控**。

**终端里没有文字？** 检查 Terminal 菜单 **Shell → 安全键盘输入** 是否关闭；iTerm2 等其他终端同类选项也要关闭，并确认光标在可编辑位置。

**蓝牙耳机切换后录音中断？** 音频路由变更会保护性停止，重新长按 Option 即可继续。

**提示需要 API Key / 服务返回鉴权错误？** 到设置里检查 API Key 是否填写正确，以及「模型版本」是否与控制台开通的资源一致。

**结果留在剪贴板、没有自动粘贴？** 说明当时处于安全键盘输入或缺少辅助功能授权（见上文「权限」），手动 ⌘V 即可。

**松手后一直没出字？** 查看 `/tmp/voicetext.log` 里的连接与响应日志；常见原因是网络不可达、API Key 失效或资源未开通。

## 开发

macOS 13+，Swift 5.9+，无第三方依赖。

```bash
# 运行（加 --settings 启动后直接打开设置窗口）
swift run VoiceTextApp
swift run VoiceTextApp --settings

# 测试
swift test

# 打包
./scripts/build_app_bundle.sh
```

打包脚本优先用本机的 `VoiceText Local Dev` 证书签名，没有证书时退回 ad-hoc。保持签名身份稳定可以避免每次重建后麦克风/辅助功能授权失效。

推送 `v*` 标签会触发 GitHub Actions 自动构建并发布 Release。
